- 当前卷剩余约 111 GiB，足以保存本轮轻量模型和逐点产物。CPU 8 逻辑核；系统 Python 3.13 含 torch 2.12.1，CPU 前反向和权重复载通过，MPS 不可用。验证环境 Python 3.12 含 numpy、pandas、scipy、h5py、matplotlib 和 python-docx。

- 固定配置冒烟成功：一条 P1 原始事件按目标前缀重建；官方 CK1 输入止于 2025-02-07 23:59:52；模型 pickle 在新进程复载差为 0；官方框架在 sample_data 完成 train/test；Torch CPU 模型完成前反向和权重复载。
- 根目录 `my_model/__init__.py` 仍激活 ExampleModel。研究过程不切换正式提交模型，待 R6 决策后才形成研究候选包。

## 数据资格

- D1 可做六芯严格浅充裁剪代理开发，但不是独立确认。
- D3 官方只有 CK0 容量公开，CK1–CK7 只作严格前缀回放。
- Che 和 TU 已下载且可读，分别限于部分充电形状与阻抗/异常。
- 新检索未找到完全兼容的独立 4S、102 Ah、5.1 A 至组压 11.2 V 数据。He ESSL1 是 16S 且许可/协议待澄清；Xu 只有一个 1P10S 53 Ah 模组；Ulfat 8S 数据是确定性容量轨迹和生成变量，不能作独立真实确认。

## 运行限制与应对

- 沙箱禁止 `ps` 和 `sysctl`，无法用它们核查进程和物理内存。每个实验使用唯一 run 目录、逐折检查点、完成 JSON 和输入哈希；恢复时按这些文件判断，禁止覆盖。
- 深模型只能用 CPU，优先小网络和固定三种子。若运行中断，从 held-cell/seed 检查点继续。
- `independent_capacity_confirmation=false`，`official_capacity_accuracy_verified=false`；这两个字段不会因 D1 低误差、接口通过或外部异协议结果而改变。

R0 通过，允许进入正式研究训练。正式顺序为 R1 配对机制消融和尾部方法，随后 R2–R6。
