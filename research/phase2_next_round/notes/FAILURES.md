# 失败与受限操作

## R0

- 沙箱不允许读取 `ps` 和 `sysctl`，因此不能从这两条命令确认活跃训练进程及硬件内存/CPU；磁盘检查可用。后续用唯一 run 目录、完成标记和输出存在性避免重复覆盖。
- 隔离验证环境含 numpy/pandas/scipy/h5py/matplotlib/python-docx，但不含 torch；系统 Python 3.13 含 torch 2.12.1。深模型采用系统 Python并固定缓存目录，Word 使用隔离环境。

## R5

- 测量积分器首版自测的合成电压在最后一行前恰好达到 11.2 V，而 `stop_reason` 仍为 running，正确触发协议失败。修正合成曲线使首次越线与停止原因位于同一行后重跑；积分算法未放宽。

## R1 与独立审查

- 原 `no_temperature` 只清零序列温度通道，监督头仍可见元数据 `current_temp_C`。此前“温度稳定增量”的解释撤回；原 run 保留为失败审计。本轮新增 `no_temperature_strict`，同时清零序列通道与元数据第 8 列并完整重跑。
- 严格去温度在外层六芯面板上改善宏 MAE，但恶化最差芯和最大误差。它是在独立审查后为正确性补跑的条件，没有用内层实体规则选择，因此不能直接升级为锁定候选。
- 末期 2 倍权重也未实现按内层实体冻结的尾部选择器；仅作为探索对照，不写成预注册选模成功。
