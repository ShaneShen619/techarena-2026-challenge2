# CK0 hold reference package

Official-interface reference that returns the released CK0 5.1 A capacity divided by 102 Ah at every checkpoint. It deliberately does not update hidden CK1–CK7 capacity. Its interface and causal behavior can be tested; its hidden-point accuracy cannot. This is a conservative research reference, not a validated aging forecast.

Run with the copied official `run_model.py` from this directory, using `--input` pointing to the original `data` directory and an output directory outside this clean candidate package.
