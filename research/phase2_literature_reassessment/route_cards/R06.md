# R06｜多事件 ICA/DVA 与退化模式门控

**状态：**保留机制诊断，暂不作绝对容量主估计。本卡是可证伪方案，不代表已实现或官方性能已达标。

## 科学问题与正反证据

Q2/Q7：峰形变化是否能提示窗口失效、LLI/LAM 或末期机制变更？ 依据与反证：A_Krupp2021 四串同质/异质 ICA 条件；Yagci2025 低倍率pOCV+半电池拟合；A_Figgener2024 现场 LFP 特征弱；Bilfinger2024 在106s1p LFP近全程低功率充电中保留部分DVA峰，但ICA噪声大且BMS上限变更伪装SOH；A_Ovejas2019 滞后影响。

## 新增信息、官方可用性与锚点

- **新增信息/先验：**重复事件峰覆盖、峰位/面积与限压芯身份提供质量/机制代理。
- **字段、事件与缺项：**优先相同温度/方向/电流的多次近CC完整可见片；10s采样及多窗合并；无足够峰区便不求导。
- **CK0与识别边界：**CK0 C/20曲线只作带载对照；半电池参数若无实测，LLI/LAM 只能是待验证解释。

ICA=dQ/dV，DVA=dV/dQ；按原始电压量化和窗口宽度做稳健性扫描。峰时变特征不直接等于 C/20 组容量。

```text
estimate: if qualified multi-event coverage compute peak diagnostics; gate R02/R03/R04 update; do not independently return Q
```

仅持久化外部或在评价时点以前可用的标定、参数和 CK0。`fit(load_dataset(input))` 在官方框架中可见完整操作数据，因此必须以逐检查点前缀重建任何目标统计；不让未来事件、标准化或窗口选择进入早期预测。

## 混淆、反证、评价与回退

- **处理：**微分放大噪声、平台低斜率、温度/路径滞后、四串峰叠合及不均衡。
- **强基线/消融/划分/指标：**同寿命重复事件/跨温假变化率，和独立容量/半电池诊断配对；用真实末期而非合成器自身标签反证。
- **预先定义的否定或回退：**峰不存在/宽度敏感/换温误报时关闭门控特征。
- **成本与依赖：**特征原型约 1–2 人日；机理确认需要额外低倍率/半电池实验（估计）。

所有容量结果均按物理实体、温度与末期列出 pp 误差及不确定性；未知官方 CK1–CK7 只做前缀和质量自检，不给虚构性能。D1 目标宏≤1 pp、最差≤2 pp、最大≤5 pp 保留为未来挑战目标，必须通过内层选择与独立确认；未达到仍可完成研究报告。
