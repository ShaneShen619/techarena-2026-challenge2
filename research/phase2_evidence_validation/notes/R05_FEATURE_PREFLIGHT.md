# R05 D1 v1.5 feature preflight (preparation only)

Status: read-only audit and proposed comparison; no model was trained. The existing `configs/r05.json` and frozen manifest were not changed. This note does not turn the six-cell P1 proxy into evidence about hidden official CK1–CK7 group capacities.

## Boundary and source facts

- Main D1 view is 6 physical P1 cells × 30 targets = 180 rows, persistent history, 20 Ah trailing observed fragment, native roughly 30 s sampling, ending at the **first measured 3.50 V crossing**. The 952 distinct selected 20 Ah events are reused across targets. `M9_D1_v15_inputs_v1/summary.json` records the crop/visibility hashes and 952 events; `M9_D1_v15_target_map_v1/summary.json` verifies every selected fragment ends strictly before target discharge. Source: `../phase2_method_exploration/scripts/m9_build_d1_v15_manifest.py`, `m9_crop_d1_v15.py`, `m9_d1_v15_target_map.py` and corresponding run outputs (paths from repository root: `research/phase2_method_exploration/...`).
- `D1Visibility.get()` is the model-facing boundary. It returns the anchor capacity/time, target cutoff, prefix-qualified charge count and selected cropped fragments. It excludes target labels and full-charge depth. The target map adds 16 slots: current, first 10, recent 5, with current potentially duplicated, so at most 15 distinct allowed events per target. The same 180 labels from frozen `research/phase2_temperature_improvement/outputs/panel_main.csv` are the high-rate **single-cell discharge proxy**, not the official four-series, 5.1 A to first 11.2 V pack target. The target map's metadata columns are exactly `[anchor_pp, age_days, age_log1p, history_count, last_gap_days, prefix_prequalified_charge_count, current_A, current_temp_C]`.
- The official `data/DATA_DESCRIPTION.md` instead exposes `timestamp`, `elapsed_s`, `chamber_temperature_C`, charge/discharge cumulative Ah, and `temp_mean_C/temp_min_C/temp_max_C` on 10 s operation rows. Counters bridge within-segment recording gaps but exclude checkup throughput; segment 3 is absent. `framework/data.py` truncates with `timestamp <= until`. These official fields must not be silently assigned to P1 D1 views. Conversely P1 `temperature_C` is a cropped single-cell event median, not an official pack's three sensor statistics.

## Feature availability at each target

| Family | D1 v1.5 strictly available | What it means / limit |
| --- | --- | --- |
| Anchor and calendar | `anchor_pp`, `anchor_discharge_start`, `target_discharge_start`, hence `age_days`, `age_log1p` | Anchor is the prior first P1 discharge. Calendar age is known at the target; it also proxies protocol progression and event frequency. `target_ordinal` is for grouping and late scoring, not a predictor. |
| Charge/event throughput proxy | `prefix_prequalified_charge_count`; `history_count`; `last_gap_days`; fragment `observed_span_Ah`; `current_A` | Count is **prefix-qualified charge events**, not cumulative charge/discharge Ah or EFC. The 15 selected fragments cannot reconstruct all lifetime Ah. Fragment Ah is approximately the fixed 20 Ah observation budget and mainly checks coverage, not lifetime throughput. Full-event charge depth, post-3.50 V rows, target discharge, and any future rows are forbidden. |
| Chamber | No `chamber_temperature_C` column in the D1 adapter or P1 cropped-event table. The cell ID embeds nominal 25/35/45/55 °C and 0.5/1C protocol. | Parsing nominal chamber set point from an audit ID would be an **identity/protocol proxy**: each condition has only one or two cells and is entangled with rate and physical cell. Keep IDs out of model features. A nominal-condition arm requires a new, explicitly approved/versioned input contract, and still cannot identify a chamber effect. |
| Measured event temperature | `current_temp_C`, each allowed fragment's `temperature_C` (median of raw selected rows within the crop) | This is measured before the target. For the 20 Ah crop table, 51/952 event temperatures are missing; preserve a missing indicator. The prior sequence file encoded missing temperature as zero after scaling, which does **not** preserve missingness as a separate feature. In observed events the medians span roughly 33.5–60.9 °C across cells; current is about 50 A or 100 A by protocol, tightly coupled with cell identity. |
| Thermal history | Temperatures and start/end times of only the allowed first/recent cropped events; e.g. median/mean of 15 unique event medians, recent-minus-first, hot fraction among observed events | This is **sampled event-temperature history**, not continuous `∫w(T_cell,SOC)dt`. Unselected events, rests, discharges, gaps and SOC are absent. No point estimate of full thermal exposure is identified. If an integral is attempted, report observed-duration contribution and explicit unknown-gap bounds, never impute unknown intervals as measured exposure. |

Source code for the scalar feature frame is `research/phase2_method_exploration/src/m2_features.py`; crop temperature is built in `scripts/m9_crop_d1_v15.py`. The P1 raw rows do contain `absolute_time`, current and temperature for selected source cycles, but using unselected portions or full-charge endpoints would create a new information budget. A causal all-history Ah/temperature reconstruction would need a new version, own cutoff audit, and equal rebuild of every comparator.

## Implementable equal-budget comparison

Keep the exact v1.5 180 target keys, anchor, 20 Ah crop, 15 distinct-event allowance, and six outer leave-one-physical-cell-out folds. All arms predict `target_soh_pp - anchor_pp` and add the same anchor at output. Use one intercept plus standardized ridge with the already frozen penalties `[0.01, 0.1, 1, 10, 100, 1000]`; fit medians, missing indicators, centering and scaling on each training split only. Preserve one row for every target and score fallback as part of the denominator. A minimal feature registry for **existing adapter fields** is:

1. `CK0/anchor`: zero loss change, a mandatory constant comparator.
2. `time`: `age_days`, `age_log1p`; optionally `last_gap_days` with missing flag, fixed before fitting.
3. `count/time`: time columns plus `prefix_prequalified_charge_count`, `history_count`. Call this a throughput **proxy**, not Ah. A true cumulative-Ah arm cannot run under current D1 input contract.
4. `instant T`: count/time plus `current_temp_C`, `current_temp_missing`, `current_A`. This tests measured temperature conditional on age/count/rate, though rate itself is nearly protocol-specific.
5. `sampled T history`: arm 4 plus mean temperature of unique allowed first 10, mean of unique allowed recent 5, recent-minus-first, observed-event temperature coverage, and missingness indicators. De-duplicate current; derive only from `allowed_event_ids_json`/crop rows ending before cutoff. This is an event-history proxy, not full exposure.
6. `matched no-T basis`: same number of added scalar columns as arm 5, built from non-temperature prefix timing/coverage (`first/recent observed event count`, `last-gap`, observed fragment sample count/span/current summaries), with the exact basis declared before any score review. Compare with both arm 4 and 5 to check whether extra dimensions or event selection explain gains. A time/count-only model with fixed capacity matching is also a negative control.

An exploratory `nominal chamber` arm could add a numeric chamber set point **only after a versioned D1 metadata contract confirms it independent of IDs**; it must be labelled condition association, never causal chamber effect. Under the frozen current adapter, mark chamber-only and true-Ah cells `not_testable`, rather than fabricating values. This is the necessary v2 input/protocol change identified by this audit; do not alter the frozen v1 config in place.

For each outer fold, use its five training cells only. For each ridge penalty, perform five inner leave-one-training-cell-out fits. Select penalty by mean of the five inner cell MAEs, deterministic smaller-penalty tie-break; then refit on all five and predict the untouched sixth. The frozen R05 selection says to output a separate tail-priority result but does not specify its exact scalar rule. Before running it, version and freeze one (e.g. minimize `0.5 × inner macro MAE + 0.5 × worst inner cell late MAE`, late = target ordinal ≥21), without inspecting outer outcomes. If arm choice itself is selected, choose it in the same inner folds; do not report the best outer arm as a selected winner. The six outer cell results are paired and each cell's 30 repeated targets remain one entity for uncertainty.

Report 180 predictions per arm, physical-cell macro MAE, worst-cell MAE, maximum absolute error, late MAE, late signed bias/high-overestimate rate, and each arm's paired differences versus anchor, time/count and matched no-T basis. Preserve existing historical best as a separately labelled frozen reference because it was already developed on these six cells. Repeated seeds/LOCO do not create independent confirmation.

## Negative controls and interpretation

- Freeze a model, then modify only post-target source rows or remove future events; every earlier feature and prediction should remain invariant. Separately test `fragment_end == cutoff` at the official `<=` boundary; D1 legacy scripts use strict `<` and this difference needs an explicit convention rather than accidental leakage.
- Permute measured temperatures **within each cell and age/event-count stratum** on training folds only, preserving availability and the strong condition structure. Compare the added benefit of true vs permuted temperature. Shuffling across cells would break condition and overstate evidence.
- Replace temperature history with its within-cell lagged/missingness pattern and compare equal dimension; use a fixed-model ±temperature perturbation to detect instantaneous sensitivity. Neither is a substitute for reference-temperature capacity labels.
- On D1, temperature, current rate, calendar age, and physical-cell protocol are strongly coupled. An across-cell correlation may predict the P1 proxy while failing to identify thermal aging. Prior v1.5 prefix-temperature scalar experiments gave RBF macro 3.10 pp/worst 5.63 pp and MLP macro 2.67–3.42 pp across seeds; these were same-six-cell development runs. An older full-event temperature study found full-prefix mean T plus current T macro 2.99 pp, but it used complete earlier P1 charges rather than the 15-fragment v1.5 budget, so it is contextual evidence only. (`research/phase2_method_exploration/runs/M9_D1_v15_prefix_temperature_v1/summary.json`; `runs/M3_prefix_temperature_v1/summary.json`.)
- If sampled-history wins only against weaker age baseline, loses to matched no-T, worsens worst/late cells, or is unstable to missing bounds/permutation, classify incremental thermal information as unsupported or uncertain. Even a robust D1 gain remains proxy development. R05 group-level hierarchical slopes/variance and separation of reversible operating-temperature response from irreversible degradation require independent physical groups with repeated **same-protocol, common-reference-temperature** capacity tests; CK0 of one official group only anchors its intercept. Official CK1–CK7 remain unlabelled.
