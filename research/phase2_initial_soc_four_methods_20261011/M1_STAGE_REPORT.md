# M1：找起点，再记账


假设：可信操作终点与连续净Ah能减少任意重置的自由度。

输入与因果边界：已结束CCCV、前静置、原始共同电流与连续时间链；未使用未来满充。

实现与对照：按固定锚点规则追踪参考Ah，比较共同／逐芯起点、固定／更新伸缩、朴素满充重置。

结果：71/75条事件可连接，评分直接覆盖44/46；M1_cell前向A/B为1.882/1.320 mV，配对主基线0.489/0.636 mV。模拟正例M1 SOC MAE 7.066 pp，优于朴素满充31.576 pp，但未到3 pp状态目标。

反例与失败：少充、均衡、电流偏差和容量变化时，同一Ah不对应同一SOC百分比。操作充电终点并不能证明四芯100%。

证据等级：S为固定生成器机制重复，O为此前曝光官方单组的冻结规则前向回放；合法R独立逐芯SOC与后续同协议容量真值缺失，真实准确性不可测。18项科学不变量检查通过，不等于统计精度或容量门通过。

传入下一阶段：相对Ah传播规则传入后续探索；不作为已通过精度门的SOC观测。

最终用途：operation_bookkeeping_only_not_accepted_SOC_or_voltage_predictor。补充诊断在主评分后完成、未更改冻结模型，不当作新的封存接纳证据。
