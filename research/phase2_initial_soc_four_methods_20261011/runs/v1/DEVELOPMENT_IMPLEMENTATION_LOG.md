# 最终评分前的实现修正

- 首次开发试运行在合成capacity_only的模板最大边界因浮点误差中断；未产生完整开发评分，也未打开最终种子。对边界增加1e-9 Ah数值容差，不扩大物理模板域。
- 科学检查的置换容量例原先超出有限模板域，改用在参考曲线覆盖内的小异质性例；强异质性仍由域检查拒绝，未扩大尾端。
- 机制M4改为以前一个已完成控制充电/放电事件的参数驱动第二个起点多缺2 Ah的独立生成轨迹，避免把目标完整事件拟合参数称为在线可用。
- 显式实现固定起点只伸缩的历史拟合、M1固定净电量约束的伸缩分支；M4保留同操作锚点链内校正后的参考电量位置。
- 静置预算使用最早出现的5/15/30分钟前缀，并要求实际覆盖至少90%预算；没有足够静置不假装测得恢复幅值。
- 无合格M1锚点及无合格M3恢复段使用开发冻结的公共回退，并单列直接模块覆盖。

以上是算法语义、因果性和域检查修正，均在最终评分前完成。开发阶段允许这些修正；正式评估后不据表现再修改实现或门槛。
