将问题拆成三个层次：

1. **测量证据**：某个可见片段是否携带可与工况区分的健康信息？
2. **容量映射**：该证据是否改善真实标签下的容量预测，而不仅改善电压拟合？
3. **官方迁移**：在四串、浅循环、不同温度及官方截止条件下，映射是否仍适用？

最优先目标：提高官方相似输入条件下的可信度、准确度、最差组表现和不确定性质量。P1 深充成绩作为辅助回归指标，不让其主导所有路线选择。

### 3.1 证据分层

- D0：既有 P1 六芯深充开发面板。复现用于回归和消融，保持旧面板 SHA256 与目标清单；新增密集目标单列。

- D2：通过来源、标签和实体核验的真实浅循环/独立数据测试。优先检查本地尚未参与选择的数据；只有确实未看过的实体或新来源才能称封存确认。Che 标签口径不同则单独评分，不与 P1、官方标签混成一个 MAE。

- S：合成机制与反证。用于容量/SOC/阻抗/偏置/温度混淆和边界检查，单列结果；不当作真实组容量确认。

D2 不可得时，M1–M9 仍须推进 D0/D1/D3/S 中可执行的工作。明确记录“独立容量确认未完成”，不能生成伪标签冒充 D2。

### 3.2 分组、时间与输入公平性

- 外层按物理电芯/电池组隔离，内层同样按实体选择特征和参数；归一化、插补、温度面、模板、阈值、编码器和误差校准均遵守训练折边界。
- 加入留温度组、按时间向前滚动、固定每实体权重的敏感性检查。未来标注容量只能进入评分器，不能进入事件提取、模型状态或预处理。
- 同一实体的全部裁剪、增强、标签和重复记录必须留在同一分组；按电池组自举，不能把相邻周期当独立样本制造显著性。六芯的置信区间局限必须写明。
- 确认集开封前冻结候选、参数、代码和清单哈希，只用一次作确认；开封后若用于修改，改称开发数据并找新的确认集，不能保留“盲测”称呼。

- 全周期官方数据可用于明确标识的回顾性分布诊断，但利用后期分布选窗或设门限的方案只能称回顾性/域适配实验；严格在线主结果的窗口/门限从外部训练数据、官方说明或当时可见前缀确定。不能把 D3 后期预测外观拿来调早期结果。
- 每条路线同时报告信息预算、锚点数量、使用时长、窗口与模态。深充特权模型只作上界诊断；浅充主比较中的基线必须接受相同可见输入和同样质量门控。

冻结并真实运行：CK0 常数、合法前缀的低维年龄/吞吐量先验、旧官方备用分支、当前完整模型、当前局部无温度简化模型、整段 CC Ah 特权诊断模型。对每个新通道加固定参数/无温度/无该通道等必要配对消融。哪个基线有输入资格、回退如何计分，必须在看候选结果前写清楚。

- 因果、单位置换、积分、序列化、重复调用、冷启动、缺口和输入污染测试为硬性正确性要求。任何性能改善不能抵消严重正确性错误。

- `runs/<run_id>/`：执行配置、stdout/stderr、逐点预测、事件日志、权重、划分和评估结果；失败运行也保留。
- `notes/RESUME.md`：恢复顺序、已启动进程 PID/会话、最后完整检查点、下一实验与不可重做的封存评估。

用不可覆盖 run_id、原子写入和完成标记保存长计算。恢复先查进程和日志，避免重复启动相同任务；不重复下载或每次重扫整套 TU。按系统/文件分块处理，先查磁盘/RAM与小样本吞吐，缓存只存必要产物。硬件资源不足先减批次、压缩和顺序执行，不能删难样本改变主协议。

正常研究提供简短进度说明：发现、证据、剩余不确定性、下一步。长工具调用按可用机制分段等候，不把“正在运行”当作完成。发现无关旧文件变化时保留并避免覆盖。

## 5. 逐模块执行

统一闭环：问题与假设 → 文献/代码证据 → 最小实现 → 正确性与因果检查 → 预注册评估 → 失效分析与反证 → 接受/拒绝/限定适用范围 → 保存交付 → 下一模块。

每个可行路线至少实现一个简单基线、两种有不同机制假设的候选，并完成有针对性的消融或反证；不靠换随机种子凑“尝试”。若结构上缺少必要观测或标签，先做实际字段/可观测性检查及可执行机制实验，记录缺失，再继续其他模块。不能要求先获得 CK1–CK7 真值才开始。

### M0：基准、环境、数据资格和历史复现

1. 核对目录、文件哈希、原始数据说明和标签生成规则；区分观测容量、制造商标称值、BMS 估计值、伪标签。
2. 新目录中复现本次七组消融及脉冲候选数量，使用独立输出，禁止调用会覆盖旧冻结结果的脚本。对差异定位至输入/代码/版本，不强行对齐数字。
3. 冒烟：一芯一事件特征、一次折内训练、一段官方历史前缀、一个检查点、序列化后新进程预测；核实 JSON/CSV 可写、科学绘图可生成。
4. 建立 D0/D1 清单、逐目标历史可见性预算和标签隔离层，盘点 D2 资格，冻结基线、第 3 节指标和逐路线必要实验矩阵。对额外公开数据只下载必要元数据/代表文件先验证，不让联网失败拖住主线。
5. 写出 `notes/READINESS.md`：ready / runnable_with_limits / blocked，逐项标注哪些路线能做容量验证、只能做信号验证或暂缺关键数据。

### M1：认证标准放电、充电结束和静置事件

1. 从官方原始时序重新识别候选，核验电流符号、时间连续性、前序 CCCV、组压/芯压、温度稳定性、约 30 分钟持续时间以及累计 Ah 一致性；输出每段接受/拒绝理由。
2. 明确 41 是初筛候选数，不预设全部合格；后续数量变化必须解释。高组压不等于每芯相同 SOC；是否均衡、是否存在可用静置，按实际信号判断。
3. 按电芯建立同一放电 Ah 坐标下的 V(q)、斜率、压差、10/30/60 秒响应和慢极化特征。只使用传感器分辨率实际支持的参数；无静置则关闭静置通道。
4. 比较温度/前序状态匹配、固定参数 ECM 和低维动态特征两类候选。按时间向前预测后续事件电压，并在有适配标签的数据上检验容量增益。
5. 反证固定约 10 Ah 放电量不能被当容量；检查容量不变、SOC/温度/阻抗变化时是否误报老化。输出事件图册、特征与适用性清单。

### M2：支持浅充和缺失窗口的容量映射

1. 从局部无温度模型出发，比较固定共同窗口、窗口专家组合、带缺失掩码的模型；比较 Ridge、可解释样条/GAM、GP 及数据量允许的小树模型。
2. D1 覆盖不同起始 SOC/电压、15/20/30 Ah 输入量、窗口稀疏程度、采样降频、电流变化和缺口；真实浅循环与深充裁剪分别报告。训练裁剪不能使用未来真实容量选择片段长度。
3. 禁用整段深充 Ah、未来吞吐、目录工况身份等不公平信息；可使用的事件年龄和累计吞吐要明确单列消融。检查现有温度交互项使用全部 24 窗口的问题，保证缺窗情况下不偷用未观察窗口。
4. Che 先查电压网格、单位、原始实验对应关系及充电标签；资格成立时作独立域补充，标签协议不兼容则只验证形状和方法行为。
5. 固定容量改变充电深度、固定输入条件改变容量，分别做反证。输出各窗口的支持范围、缺失鲁棒性和按实体误差，不只给总体均值。

### M3：温度即时效应、累积老化与传感器偏置分离

1. 阅读第一阶段温度面的物理解释、训练来源及 Arrhenius 单位。复用思想，不把其冷却下限、自发热参数或全寿命均值直接当官方系统常量。
2. 三类单独实验：当前事件温度对电压/极化的可逆修正；前缀温度暴露与慢老化；温度偏置/缺测/滞后影响。实测可信温度优先于估算温度。
3. 找温度切换附近、相近前序状态的匹配事件，排查日历时间混淆和配对不足。若缺相近老化状态的温度配对，只能给条件相关性，不写因果温度系数。
4. 比较不校正、简单连续线性/样条修正、受约束物理修正；比较当前 T、ΔT、历史暴露、交互项各自的价值。参数在训练折内估计。
5. 将 ±1°C 传感器偏置与真实温度变化分开压力测试。报告在 M1/M2 中的性能、覆盖和不确定性；无效温度项允许删除，不能强制证明温度有益。

### M4：带可辨识性检查的低阶状态估计

1. 从最少状态的 ECM 开始，再逐项加入容量慢变、SOC 偏移、极化、滞回、电压偏置。至少对照固定参数模型与带门控慢参数估计模型。
2. CK0 曲线用于初始有限倍率参考，不称完全平衡 OCV，不假设单个组容量唯一决定四个芯容量。未知参数使用有来源的范围并做敏感性分析。
3. 检查雅可比/参数灵敏度、剖面似然或后验宽度、多初值一致性；做容量—SOC、容量—电压偏置、OCV—阻抗混淆实验。
4. 根据实际可见曲线斜率和激励强度判断能否更新容量；不可辨识时保持/传播状态并扩大区间。论文中的低 SOC 信息区若在官方数据不存在，就记录该前提不满足。
5. 先预测未来逐芯电压，再以独立容量标签检验容量；两类分数分别报告，不能只靠电压拟合漂亮选择容量。

### M5：四串组端截止容量

1. 用 M2/M4 可信信息建立每芯容量、起始 SOC、阻抗的不确定状态；统一串联电流，模拟 5.1 A 至总压 11.2 V。核实官方另有无保护截止；未经说明不自行改成单芯 2.5 V 截止。
2. 对照最小单芯比例、简化一致芯模型和显式四芯模型。检查积分单位、电芯置换不变性、时间步长收敛、能量/电荷一致性、初始 CK0 重建。
3. 使用不同于估计器的真值模型或未建模效应生成容量/SOC/阻抗不一致及组合场景；冻结扰动范围及依据，同时报告构造偏向和分布不确定性。
4. 输出组容量区间、限制电芯与机制、对初始状态的敏感性。不得用强制单调化隐藏温度可逆变化或模型失配；保留原始估计。

### M6：TU Darmstadt 工况归一化阻抗和异常迁移

1. 按系统、季节、电流/SOC/温度分布盘点完整可访问数据，不以少数系统开头 100k 行和统一高电流门槛决定整套数据无用。先元数据和分层抽样，随后按冻结规则扩展分块处理。
2. 阅读 BattGP 原论文和公开代码，核对正式版数据数量，处理主动均衡电流、工作点差异和观测缺口。复现可行的低维版本并清楚说明近似。
3. 对照固定/工作点回归阻抗与工作点＋时间分解 GP，按系统留出并向前滚动预测。在线结果用因果过滤，全寿命平滑只列离线诊断。
4. 将归一化阻抗作为 M1/M4 的辅助通道，验证其是否提供独立信息。无容量标签时只得出阻抗/异常层面结论，不制造容量 MAE。

### M7：小规模自监督表征与迁移

1. 先建可运行的轻量时序表征基线（统计/线性或储备池），再实现小型 TCN 或其他合适的序列编码器；明确架构和依赖，先实测 CPU/MPS 资源。
2. 任务可为因果下一段电压预测、历史窗口内部遮蔽恢复或跨工况一致性；推理时不能使用目标之后的输入。预训练也遵守实体隔离，含目标无标签数据的实验单列为域适配，不混入严格留域结果。
3. 对照从零训练、冻结编码器、小幅微调，以及 M2 的强低维基线；使用同输入、同容量标签、相近选择预算，随机训练给多个预注册种子。
4. 重点验证容量迁移而非重建误差。如果重建好而容量无改善，做工作点信息与健康信息的消融后记录负结果，不无休止扩大网络。

### M8：按信息质量融合与区间校准

1. 单通道先过自身验证，再比较最佳单通道、简单加权组合、按可观测性/域内程度门控的组合或状态空间融合。
2. 处理同一事件多特征的相关性，避免把重复信息算多次；数据不足时保持估计并传播不确定性。温度不匹配、长缺口和窗外输入应显式降低证据权重。
3. 做去掉每个通道的配对消融、缺通道压力、突然工况切换和参考漂移检查。报告全目标 MAE、覆盖、尾部和最差组，不以曲线更平滑代替有效性。
4. 区间只用训练/校准实体拟合，报告有限样本覆盖。不能用六芯宣称可靠的细分工况 95% 覆盖保证。

### M9：统一比较、困难案例、改进迭代与锁定

1. 汇总所有路线的输入资格、标签口径、数据独立性、误差、覆盖、鲁棒性、区间、计算成本和适用范围。不同标签/输入的结果分面展示，不做误导性总排名。
2. 对最差实体、最大误差、温度切换、浅充不足、长缺口分别定位；检查偏差来自事件、工况校正、容量映射还是组端计算。
3. 对有希望但未达标的路线，实施针对原因的新变体并重跑公平基线；对已达标路线也做反证。新假设先登记，明确与既有实验的差异；不能只扫更多参数。模块首次比较后审查 backlog，将有证据且可执行的高优先级假设纳入必做；剩余建议按“需新数据/超出本轮范围/缺少支持证据”分类，不凭空要求无限追加方法，也不能为早结束随意降级仍有明确依据的改进。
4. 首选以最相关、最独立的容量证据排序；D2 不存在时只称“待确认候选”。备选应有不同失效机制或信息需求，不只是同模型另一个随机种子。融合无优势时可以选择单模型。
5. 候选代码锁定后运行封存确认（若存在），再完成官方 CK0–CK7 逐前缀回放。记录每点实际分支、证据事件、回退、区间和诊断。隐藏点没有真值，不生成成绩排名。

### M10：复现、独立审查、读者测试和交付

1. 用独立评估脚本从逐点预测重算指标及验收字段，核查缺失、异常、目标数量与实体权重。对关键事件从原始时序重建，区别“同公式复算”与“独立特征重建”。
2. 用独立进程和干净候选目录测试接口、序列化、日期调用顺序、重复查询、前缀截断及未来数据污染；官方 validator 通过仅代表流程检查，不代表容量精度。
3. 使用当前官方资源限制做性能回归；候选包排除原始数据、研究环境、临时缓存及无关模型。保留代码/输入/权重/配置哈希和复现命令。
4. 若有子代理，让独立审查者只读审核划分、未来信息、单位、标签口径、指标和结论，再让不带聊天上下文的读者仅凭报告回答“什么有效、验证在哪、官方是否有真值、如何复现、下一步缺什么”。修复严重问题后复查。
5. 用 doc-coauthoring 思路完成中文报告，不逐章等我确认。若生成 Word/PDF，遵守相应技能并实际渲染检查；渲染受阻如实交付 Markdown 与限制，不把未验证的排版标成通过。图表写明标签协议、单位、数据范围及开发/确认属性。

## 6. 论文使用要求

以已有综述为起点，针对当前模块的具体疑问核对公开原始论文、补充材料和作者代码，记录 DOI/URL、版本、所用信号、标签、划分、假设和可迁移边界。不要用二手综述的数字替代原文，不为装饰报告无限扩展书目。

重点原始研究入口：

- 短随机恒流充电片段（含 LFP）：https://pmc.ncbi.nlm.nih.gov/articles/PMC9062330/
- 静置电压容量估计（主要 NCA/NMC）：https://pmc.ncbi.nlm.nih.gov/articles/PMC9046220/
- LFP 偏置补偿与斜率分区估计：https://arxiv.org/html/2401.08136
- aging-aware ECM/GP：https://arxiv.org/html/2407.06639
- BattGP：https://arxiv.org/html/2406.19015 ，正式论文 DOI 10.1016/j.xcrp.2024.102258；代码 https://github.com/JoachimSchaeffer/BattGP

每个采用的论文方法都回答：哪些前提本项目满足？哪些不满足？复现了哪个子结论？修改后仍称原方法复现还是新的变体？论文误差不能作为本项目验收数字。

## 8. 完成条件与最后汇报

只有同时满足下列要求，研究 Goal 才可标为 `complete`：

1. M0–M10 均有实际产物和状态；所有可行路线都有真实运行、必要变体、公平对照和机制反证。受限路线有实际核验的缺失证据及替代工作，不能仅凭猜测跳过。
2. 严重正确性、因果性和可复现问题均已修复；性能不佳可以是负结论，错误代码不能作为科学负结论。
3. 达到冻结性能目标并经过相应证据审查；或在目标未达时，已完成冻结的必要实验矩阵和 backlog 中已接受的高优先级改进，逐项给出反证、剩余差距及取得新进展所需的数据/实验。审查确认剩余假设的分类有证据、没有漏做必做实验，而不是要求证明不存在任何其他方法。后一种只能标记研究闭环完成、`performance_target_met=false`，不能称性能成功；不能把需进一步独立确认包装成已确认。
4. 比较报告、首选/备选结论或“不支持替换现有候选”的结论、复现材料、审查和读者测试均完成。有独立审查能力时必须使用；没有时按第 1 节受限检查流程完成并明确 `audit_level`，不得声称独立审查通过。报告明确哪些结论属于开发验证、独立确认、机制模拟或官方无标签诊断。
5. 全部交付真实存在，`STATUS.md` 与 `RESUME.md` 可让新会话直接接手。若仍有必要工作未完成，不能因为 tokens、单轮或时间将尽而标记完成。

最终用中文回答：研究是否完成、性能是否达标、最有价值的新发现、每条路线结果、首选/备选及适用条件、官方真实精度是否验证、剩余数据缺口和文件链接。若运行受到外部限制，说明已完成内容和恢复命令，不伪造成功。

执行时从 M0 开始，边研究边更新证据和下一步，不只返回计划。
