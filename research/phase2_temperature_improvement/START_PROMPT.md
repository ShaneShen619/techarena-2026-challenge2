## 2. 第一阶段温度答案：必须复用的思想与必须避免的误用

源码关键位置：`t_eff_phys()`、`_initial_dT_theta()`、`_fit_dT()`、`_dT()`、`fit()` 的训练温度采集与工况聚合、`_arrhenius()`、`predict_soh()`。

物理温度面：

```text
u = T_nom + k_self * C_rate²
T_eff = 0.5 * (u + T_floor + sqrt((u - T_floor)² + sigma²))
ΔT = T_eff - T_nom
```

它表达冷却温度下限与自发热，拟合的是给定工况下的运行温度。第一阶段用 `ln(tau)=lnA+Ea/(R*T_eff_K)+gamma*ln(C_rate)` 将温度连到老化时间尺度。摄氏温度用于温度面，Arrhenius 中必须用 K；37.3 kJ/mol 等先验要核查来源与单位，不硬套不同容量和设备。

源码只从当前训练电芯提取温度；一个电芯温度非空比例至少 20% 时取全时序均值，相同 `(T_nom,C_rate)` 再取中位数。参数边界为 floor 20–50°C、k 0–20、sigma 0.05–6。少于三个锚点时用数据驱动初始化，零锚点时 ΔT=0。检查重复锚点的有效秩，不能把重复样本数误认作三个独立工况；初始化与 ΔT=0 都是有不确定性的回退，不能称为成功辨识。

README 记录六芯拟合 `(35.706,3.730,4.489)`、锚点 RMSE 0.456 K，记录协议 1B 的 SOH RMSE 1.972 pp、名义温度消融 6.772 pp。这些是第一阶段开发实验记录，原验证脚本是否齐全须核查；不能把这些数当作第二阶段已经复现的结果。

严格执行以下区别：

- 全六芯温度系数只能用于“复现历史全量拟合”的诊断。留一芯评估每折重新拟合，不能加载全六芯系数；`pretrained.json` 的每个字段检查来源，任何来自被留出目标的标签或温度统计都不能成为该折先验。
- 默认使用严格协议 1B：不额外注入被留出工况锚点。`extra_dT_anchors` 的 1A 只允许单独标识的额外信息实验，不能混到主结果。
- 第一阶段的全寿命平均温度不能直接移植为第二阶段在线特征。目标电芯只允许当前时点前已经观测的温度；目标后续均值、居中平滑、未来工况分布均禁止。
- 把温度用途分成三个模块：传感器可信度/缺测估计；当前局部 Q-V 的温度和极化影响；累积热暴露对老化速度的影响。分别设计与消融。
- 有可信实测温度时优先使用事件/电压窗口内实测温度及其变化，不用温度面把真实变化抹平。物理面用于诊断、缺测回退或有验证的先验。第一阶段设备的冷却下限与自发热参数不能直接当作第二阶段四串设备的常数。
- 第一阶段目录名是环境设定值，不是传感器真值。第二阶段温度传感器的位置和代表范围须核实，不凭四个芯压就假设有四个对应芯温；没有独立芯温时记录局限。
- C_rate 的定义冻结为电流除以对应数据源的标称容量，避免用待估容量或未来真实容量计算倍率形成循环。温度面拟合的倍率口径须与源代码和数据说明对齐。
- 此温度面没有证明“局部充电 Ah 比例 = 容量比例”。温度修复成功但容量精度不足时，必须继续检查可辨识性与监督映射。

### 3.2 最终完成的硬门槛

2. 每个电芯 MAE ≤ **4.0 pp**；全部目标绝对误差 P95 ≤ **5.0 pp**，最大值 ≤ **8.0 pp**。

- 基线集合：旧 A；CK0 常数；仅修参考/事件 bug 的 A；仅用合法前缀吞吐量/时间/温度的低复杂度老化先验；预注册多窗特征但不含温度的正则化模型。M0 冻结其特征候选范围、训练/选择协议和实现规格；bug 修复基线在 M2 首版冻结后运行，老化先验在 M3、多窗基线在 M4 完成；M7 前必须全数运行。最后两者须严格折内训练，不能把第一阶段整条目标寿命模型的输出作为输入。后续每个候选对应的“相同特征去温度”另作配对消融，不能偷偷替换已冻结的多窗基线。
- 路线 B 只作已有结果背景或低成本同面板补充，不重启整个 A/B 大项目。禁止用 B 的糟糕结果替代 A 的绝对目标。

### M1：复现并拆解第一阶段温度模型

- 记录参考源码哈希，提取温度面为可单测的纯函数；复现全六芯锚点和历史拟合，报告与 README 的差值。历史完整寿命验证脚本若未提供，说明缺失；不为“复现”硬写旧数字。
- 按外层折重建热锚点，输出每折参数、训练温度拟合、被留出工况预测、残差和不确定性。被留出实测温度可作温度预测评分真值，不回流拟合。
- 比较名义温度、简单常数温升、线性温升、物理温度面；检查弱辨识性、参数触边、独立工况不足和外推。
- 对事件温度使用窗口内中位数、稳健离散度、升温斜率、起末温差、有效比例、传感器间差异（确有多传感器时），以及可信实测/估计/未知的来源标记。温度异常用传感器量程、突跳和交叉证据判断，不能因为 60°C 高于名义 45°C 就直接剔除。
- 验证常值温度、缺测、时间错位、重复采样、参数边界和 °C/K 单位。少样本 fallback 必须暴露质量标记与不确定性。
- 出口：解释“哪些思想可迁移、哪些参数不可直接迁移”，得到因果事件温度接口，才进入参考修复。

### M2：修复参考事件和温度配对，隔离 bug 的贡献

从旧 A 的实际逻辑出发写回归测试：旧实现使用约 20°C 分箱、先写参考再判断质量；同一箱可能差约 10°C；正电流 ≥5 A 不足以证明 CC；两窗口中位数实际就是均值；无近 30 天事件时返回 CK0 会产生回升。

必须修复并逐项消融：

1. 先通过事件完整性、CC 稳定性、窗口覆盖、时间/电流/温度质量检查，再登记参考。拒绝事件不得成为参考。
2. 用实际成对温差和电流差，而非仅箱号相同决定匹配。比较连续软权重与硬门控，门限只在内层训练选择；报告“误差下降但覆盖崩溃”的失败。
3. 参考绑定电芯、窗口、电流模式和来源时间，检查只能读取前缀。跨温度层首次出现的晚期事件没有新的已知容量，不能把它偷偷重新赋值 CK0。可使用经验证的跨层映射或已估状态，但传播不确定性。
4. CC/CV 分段依据电流稳定度和电压变化，不把 CV 长尾当 CC。积分不跨缺口，不混时间交叠的不同 cycle；疑点计数和回退保留在评分中。
5. 最近事件不足时保持最近可信状态并增大不确定性，或使用已验证的因果老化传播；不能无条件重置 CK0。对缺少历史可信更新者才使用初始锚点回退。
6. 保存未裁剪估计。容量上限/单调化可作单独消融，不能靠把所有 >100% 截断就宣称温度修复成功；无约束值与触发率同时报告。

重点复现：45°C/1C 参考约 52.3°C 配后期约 62.4°C；25°C/1C 参考约 43.1°C 配后期约 33.25°C；55°C/1C 两窗口比值相互矛盾。解释每项修复后参考、温差、窗口比值、更新权重与误差如何改变。

### M3：温度补偿的可辨识验证

按复杂度顺序比较，不能未经实验直接指定赢家：

- T0：可信实测温度 + 严格配对，仅修门控。
- T1：可信实测优先，物理温度面仅作缺测回退/失配诊断。
- T2：温度作为局部 Q-V 映射中的连续协变量，采用低复杂度正则化主效应和必要的 T×电流/T×窗口交互。
- T3：温度、欧姆压降、极化和容量尺度分开的受限物理补偿。电阻/极化估计必须有数据支持，不能把全部电压漂移归因温度。
- T4：累积温度暴露的弱老化先验，单独开关。缺失运行段的暴露是未知量，不能积分插值成已知完整老化史。

用训练电芯内相邻时期、相近容量的不同温度事件研究温度效应；容量标签只用于训练侧匹配与科学诊断，不出现在目标电芯在线门控中。若同容量下温度变化不足、温度与老化近乎共线，明确不可分辨的参数，采用收缩/共享参数或不补偿；不能用全生命周期相关性证明温度因果效果。

绘制每芯残差随实际温度、温差、电流、寿命阶段的关系，同时检查温差之外的系统残差。比较误差、更新覆盖、拒绝原因和复杂度。移除温度特征但保留其余处理是必做对照。不得只展示聚合相关系数。

出口：对温度修复的收益作有证据的判断，并定位剩余容量误差；即使达到中间里程碑，也继续最终目标验证。

### M4：若仍未达到最终精度，升级容量映射

优先验证“两个窗口局部 Ah 比例不能代表容量”的剩余假设。主线仍围绕可解释、可部署的温度处理，不无界扩展模型清单。

1. 多窗监督模型：在训练折选择窗口，形成局部 Ah、曲线均值/方差/形状、相对初始参考的变化、事件温度/电流和质量特征。优先 Ridge/低自由度样条，再考虑小规模 GP。预测容量变化或 SOH；输入和标签单位、CK0 标定及跨数据集归一化全部显式定义。逐项比较 T 特征和曲线特征的增益。
2. 受限曲线对齐作为竞争方法：区分容量伸缩、SOC 起点偏移、电压偏置/极化。给可辨识性检验、边界与退化策略。LFP 平台区证据不足时拒绝更新，不用任意动态扭曲把任何曲线拟合到一起。
3. 若两者均有互补优势，可比较由训练侧质量特征驱动的组合；不能根据目标误差事后择优或按测试电芯 ID 切换模型。

参考本地证据卡并回到原文核实：Deng 2022 的局部容量增量多特征监督映射；Che 2023 的局部充电曲线与迁移；曲线对齐论文的适用条件。不能把论文报告误差当本项目结果。Che 方法若依赖有标签目标微调，要明确 CK0 单点并不等同其设置。

Che 可做独立的按电芯分组的辅助训练/检验；先审计是否与已有训练来源重复。只有无歧义的特征/协议映射才可迁移；否则作为单独研究结果。充电容量不与 P1 放电容量合并评分，不虚构其温度时序、电压网格和 C/20 标签。

M2–M4 完成首轮比较后，无论是否达到精度门槛，均以当前最佳合法候选进入 M5–M7，获得迁移、压力和审查反馈；不能以尚未完成 M5–M7 的验收项阻止进入这些模块。最终验收失败时返回对应模块有目的地改进，再重跑受影响的后续验证；每轮保留版本、搜索空间和失败结果。若修改算法家族，重新在内层选择，不能直接根据外层最差点拟合补丁。

### M5：四串迁移与无标签现场诊断

- 将最终候选用于官方四串接口，保持 CK0 精确锚定。逐 CK 输出每芯/每窗口事件、温度来源、配对温差、参考年龄、分歧、更新/回退与不确定性。不能把四个单芯容量简单平均或取最小就宣称等于组端 C/20 容量；聚合规则及截止限制须有机制与合成验证。
- 25/45°C 切换前后分别查看容量变化与输入证据，不能仅为了曲线平滑而去除真正老化变化。CK1–CK7 只做无标签诊断，不输出 accuracy/MAE。
- TU 先复用既有审计，固定系统 25、1、8 的连续前缀窗口作缺温、温差和事件检测压力验证。流式读取，记录覆盖；主动均衡电流与温度传感器位置单独处理。没有容量标签就不训练 SOH 监督目标，不将 BMS SOC 当真值。
- 明确 P1 单芯高倍率放电容量向官方四串低倍率容量迁移的剩余风险。没有 E4 真值不是本 Goal 的新增下载阻塞。

### M6：温度压力测试与科学正确性测试

冻结测试配置后再跑，温度扰动必须区分两种情形：只改传感器读数测试估计鲁棒性；改变真实温度时要由独立生成器同步改变电压/极化/可用容量等物理量。不能只改温度列就声称模拟真实升温。

实测主面板传感器压力场景：

- 主压力实验冻结干净训练得到的模型、超参数和门控，只扰动留出目标电芯截至预测时点的全部可见温度历史，包括初始温度参考和在线状态输入；容量锚点/评分标签不变。每场景从初始状态重新按时间回放，隔离或清空派生特征、参考和状态缓存，不能读取未扰动的目标温度。训练侧扰动另列实验，不混入硬门槛结果。
- 全温度传感器一致偏置 +1°C 和 -1°C，分别运行；两场景均要求宏 MAE 相对干净值增加 ≤0.5 pp、有效更新覆盖率下降 ≤10 个百分点，且无 NaN/崩溃。这是最终硬门槛。
- ±0.5/±2/±5°C 偏置、缓慢漂移、卡常值、20% 随机缺测、连续缺测段、温度与电流时间错位；固定种子并报告误差与降级，较大扰动不强行要求与干净一样准确，但必须有可追溯降级。
- 每个扰动保留同一评分分母，报告错误自信、回退率、参考污染和恢复时间；不能从读取被扰动列以外的隐藏原温度恢复答案。

机制仿真：至少 20 个固定独立测试种子，生成器与估计器不同参数/阶次，训练和调参种子与测试种子隔离。设置恒容量变温、恒温衰减、变温叠加衰减、传感器偏差、自发热改变、4S 不一致与截止限制。记录真实目标定义，独立计算 C/20 放电容量；机制结果不能代替实测硬指标。仿真参数范围与噪声先写配置，失败后不能缩小范围隐去难例。

M0 为每项测试标注 `hard_assertion` 或 `diagnostic` 并固定容差。上述每类机制场景都覆盖至少 20 个测试种子。机制仿真的估计 MAE、温度假衰减幅度和恢复时间属于诊断，不额外隐含“零误差”门槛；但缺场景/种子、运行失败、同一估计器生成真值、真值计算错误不可验收。独立 C/20 放电积分的步长减半容量差须 ≤0.1 Ah，否则继续提高数值精度；测试相同四芯、容量不一致及 SOC 不一致三类截止情形，组端到 11.2 V 截止，不擅加官方未定义的单芯截止；芯编号置换应不改变组真值（容差 1e-6 Ah）。温度改变下可逆可用容量变化与不可逆老化容量参数分别记录，不能将两者相同作为仿真假设。因果/隔离/数学单测的硬断言在 M0 列全，评估后不得转成 diagnostic 来绕过失败。

必做回归：未来数据追加/删除/极端变更不影响更早预测；不同调用顺序一致；reference_end ≤ prediction_time；目标放电数据严格隔离；训练折 ID 与测试折不相交；一对多窗口共享事件不虚增独立样本；温度单位与 Ah 积分；缺口/重叠/CC-CV；新进程 pickle；参考不合格不入库；少温度锚点降级。只写支撑科学正确性的测试，不堆砌与实现重复的低价值测试。
