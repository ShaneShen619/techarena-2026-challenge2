# 方案 2 与方案 3：论文核对及执行 Prompt

2026-10-12。本次完成论文与作者实现核对、两份独立执行指令；尚未据此训练新模型。未更改当前实验分支或正式模型。每份指令要求未来执行者先创建独立实验分支，并保护既有结果。

## 两份可直接使用的 Prompt

1. [方案 2：四串动态模型与容量联合估计](方案2_四串动态模型与容量联合估计_执行Prompt.md)。让实际运行 V/I/T 约束容量，先解决起点、极化、偏置和容量之间的混淆。包含标定条件不足时的相对模型分支、前向测试、参数剖面、四串参考截止和 A 的弱先验/质量门。
2. [方案 3：CCCV、静置、脉冲联合特征](方案3_CCCV静置脉冲联合特征_执行Prompt.md)。建立事件“体检表”，先用真实容量标签检验多阶段信息增量，再审查迁移及单芯到四串转换。包含标签不足时仍能完成的实验、严格实体划分、论文基线、工况反证和 A 的折外残差修正。

全文本身就是 prompt，无需再拼接聊天背景。在新任务中可说：“请读取并完整执行这份文件，先建立独立实验分支，再按阶段实施；不要把未验证的结果接入正式模型。”然后指定文件绝对路径。两项若同时运行，应使用不同 worktree，避免共享工作目录切换分支。

## 精读后影响方案设计的发现

**Zhou 2025 不是现成的四串 1RC 模型。**其主模型是 OCV 加工况相关电阻，容量与电阻的慢变化由 GP 表达，段内联合估计、段间继承参数。初始 OCV 和段起始 SOC 是关键前提；本项目需要补状态连接和动态响应，而不是直接换一个滤波器。[原文 §2–3](https://arxiv.org/html/2407.06639v5)

**Yi 的价值主要在于“有信息才更新”。**专门激励和 OCV 标定支撑其分区辨识；官方 10 s 数据无法照搬高频激励，也不能按未知 SOC 硬分区。因此方案 2 改用可见 Ah 跨度、局部灵敏度和干扰重拟合检查。[原文 §II–IV](https://arxiv.org/html/2401.08136v2)

**Gasper 不只是用几个内阻指标。**论文用 V/I/T 与相对电压；已核对的代码还加入 P/I，并按 measurement_id 分组。方案 3 同时保留原始波形基线和工程特征，并把物理电芯留出作为更严格检验。[论文](https://doi.org/10.1149/1945-7111/addd50)、[作者代码](https://github.com/NatLabRockies/battery_pulse_diagnostics/blob/1c2542ab9c0d67544d1787b21871c591588c7937/run_bootstrap_xgboost.py)

**Zhu 的迁移不是零标签校正。**TL1 是输出端线性校准，TL2 是输入端仿射变换；新参数都需要目标真实标签。论文主要是非 LFP 单芯，不能将最佳误差直接移作四串 LFP 指标。[论文 Methods](https://www.nature.com/articles/s41467-022-29837-w)

## 已有失败实验如何影响新验证

两份 prompt 均纳入了最新 `phase2_initial_soc_four_methods_20261011/FINAL_REPORT.md`：约 33 Ah 宽放电与连续状态方法已经试过，当前模型仍未通过接纳门。因此方案 2 必须证明跨事件动态共享、方向处理或不确定性传播等实际改动有效；仅换 EKF/GP、让曲线更平滑不算容量证据。

方案 3 也不以几十条无标签事件强训容量。先在真实监督数据上检验，再对目标组做支持范围、工况和输出转换审查。两条路线都区分“电压预测通过”“容量可辨识”“真实容量误差达标”三个不同结论。
