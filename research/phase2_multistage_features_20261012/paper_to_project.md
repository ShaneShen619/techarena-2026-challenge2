# 论文方法到本项目的核对

Gasper 2025 DOI 10.1149/1945-7111/addd50：每个脉冲的 V、I、T、P=V−V0 作为监督输入，容量来自独立倍率容量测试。作者代码另加 P/I，并将非有限值置零；本轮稳定定义加零电流掩码。作者按 measurement_id 做50次20%留出，同一电芯跨表征测试可能同时出现在两边。本轮逐次统计这一重叠，另做整颗物理电芯隔离。原代码 baseline 筛选变量没有用于实际训练，本轮显式传入 baseline 列。使用公开最小CSV成员、按 measurement_id 连接真容量，不运行未知路径脚本。锁定 XGBoost3.1.1 并保存训练后的完整 booster 配置；这是固定现代版本协议复核，不保证重现原版本数值。

论文 Type D 为 A123 LFP单芯，表I报30芯84次测试；本轮实际CSV数量独立统计。HPPC10s放电40s静置10s充电、快速16s序列与官方20A约30min不是同一激励。原CSV可支持1s网格，本轮10s降采样只检验信息损失；不能解释成官方快速脉冲容量已经获得监督。

Zhu2022 DOI 10.1038/s41467-022-29837-w：标准CCCV满充、约30min充后静置与同循环放电容量配对。补充Table5方差用n−1；偏度和峰度用该样本标准差、分子取n平均，峰度减3，非SciPy偏差校正公式。六统计Var/Ske/Max/Min/Mean/Kur；主三统计Var/Ske/Max。Table11固定XGB lr=.8、6树、depth6、lambda1、alpha0、subsample1。训练源码未公开（原文需向作者索取），公开的是提取脚本：按控制状态取14点，用真实容量2500–3500mAh筛选。我们保留文件实体和原始时间，分别报告作者14点的实际覆盖与严格30min覆盖；容量筛选只用于论文定义复核，不用于官方。

Zenodo6379165与6405084 API文件指向同一版本，非两个独立数据集。Dataset1为NCA，选每工况文件编号最小两芯的有限子集；不足原130芯，结果称子集固定参数核查，不称完整论文复现或承诺1.1%。TL1输出线性映射、TL2输入三维仿射映射均需目标容量标签。CK0没有配对输入，不能学习任何锚定，更不能用旧B作为真值。

本项目扩展：同一单芯同循环拼接CCCV、充后静置、早期放电、放后静置；F0一致、预算一致、事件交集一致的阶段增量，整芯嵌套验证，过去局部Ah窗口趋势A及OOF残差。前后静置的方向分开编码。四芯离散F5只存在官方无标签组，不能以四通道数量替代物理组数量。不同论文数据不拼接为联合事件。

阶段一容量是0.5/1C单芯到2.5V，官方是四串C/20到组端11.2V。P1完整充电从上一循环放空开始，充入Ah天然接近下次容量，这是可见充电量的监督关系，但与官方浅充约20Ah的输入分布不同；其成功不自动证明浅片段健康特征有效。放后静置预算在P1实际容量测完后才可用，属于回顾诊断，单列。

本轮不会对四个单芯分数取平均/最小生成Qpack。没有经独立组真容量验证的初态、不均衡、截止投影转换，组容量验收UNVERIFIED。
